# 🚀 AI Content Assistant Pro

An AI-powered social media content generation web application built with **Streamlit**, **Groq**, and **OpenAI's `gpt-oss-120b`** model.

## ✨ Features
* 📱 **Multi-Platform Support:** Tailored content for LinkedIn, Instagram, Twitter/X, Facebook, and YouTube.
* 🎯 **Customization:** Choose content types, tones, target audiences, and languages (English, Urdu, Roman Urdu, etc.).
* 🖼️ **Dedicated Image Prompts:** Generates separate Midjourney / DALL-E prompts for post visuals.
* 📋 **Clean Copy & Export:** One-click copy buttons with clean plain text formatting (no asterisks) and downloadable `.txt` / `.md` files.
* 📊 **Analytics & Limits:** Real-time character/word counts and platform character limit warnings.
* 📜 **Session History:** Keeps track of past generated posts during your active session.

---

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit
* **LLM Engine:** Groq API (`openai/gpt-osbb`)
* **Language:** Python 3.10+

## 🚀 Quickstart Guide

### 1. Clone the Repository
```bash
git clone [https://github.com/Sweeta-w/AI-content.git]
cd YOUR_REPOSITORY_NAME
```

###2. Install Dependencies
```Bash
pip install -r requirements.txt
```
###3. Run Locally
```Bash
streamlit run app.py
```
